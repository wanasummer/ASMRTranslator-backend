# 音频编排主要目标

本文记录音频编排页面的产品目标和后续实现约定。它是开发与验收依据，不代表以下能力均已实现。

## 核心目标

音频编排用于对已生成的配音结果进行逐片段调整。用户的所有片段调整信息需要保存，可以试听、还原；配置完成后可加入队列，作为明确标记的“编排任务”执行。编排任务复用已有缓存，用用户修改后的片段替换对应缓存片段，再重新拼接一次，生成最终音频，并向控制台输出编排日志。

完整流程：打开已有音频结果 → 逐片段调整并保存 → 试听或还原 → 加入队列 → 执行编排 pipeline → 复用缓存并替换修改片段 → 重新拼接 → 输出编排结果及日志。

## 调整保存与还原

- 页面保存每个片段的所有调整信息，包括 TTS 时间区间、位置、语速、响度对齐设置，以及后续支持的文本或效果调整。不能仅保存中文字幕草稿。
- 保存内容关联项目、音频、稳定片段标识和来源版本；切换片段、离开页面、重新打开项目或重启应用后应能恢复。
- 持久数据应保存到项目中。浏览器本地存储和页面内存可作临时草稿，但不能作为最终编排配置的唯一来源。
- 保存调整配置与生成最终音频是两个步骤。保存后即可恢复和试听，入队后由编排任务生成最终结果。
- 保留原始生成片段和初始配置作为还原基准。还原当前片段应恢复该片段的全部调整，而不只恢复区间或语速；其他片段的独立设置保持不变。
- 保存记录需要区分原始基准、当前编辑配置和入队快照，防止后续编辑改变已经排队的任务。

## 响度对齐与试听

- “TTS语速”和“响度对齐”均为用户可调的编排参数，保存后参与最终输出，不能长期停留在仅影响试听的状态。
- 响度对齐默认以当前片段原声为参照，100% 表示与参照响度一致；用户可以自行调节。当前滑块范围为 0%–200%，0% 表示静音。
- 保留单片段与全局模式切换。单片段设置关联对应片段；全局设置在当前音频范围内共享，并以整条原声为响度参照。保存时应明确记录作用范围、参照模式和调节值。
- 入队时将共享配置与片段配置解析为每个片段的最终有效参数；全局调整影响到的片段也属于需要更新的片段。
- 原声试听、TTS 试听和混合试听用于检查编排效果。TTS 与混合试听应使用当前有效配置，与最终编排输出保持一致的时间、语速和响度处理规则。
- 还原后的试听和最终输出应使用还原后的配置。需要限制增益以避免削波时，应让用户能理解实际效果受到限制。

## 队列中的编排任务

- 用户配置完成后可通过“加入队列”提交当前音频的编排任务。
- 队列中明确标记任务类型为“编排任务”，能与自动配音任务区分，并展示来源音频、进度、结果及运行日志。
- 入队保存不可变的配置快照，包含来源版本、片段对应关系和最终有效参数。执行时使用该快照，不能读取正在变化的页面状态。
- 编排任务沿用现有队列的调度、状态和错误展示机制；任务类型用于选择对应执行入口。

## 编排 pipeline 与缓存复用

允许新增独立的编排 pipeline，承担“读取编排配置、处理变更片段、替换片段、重新拼接、输出结果”的职责。

1. 读取任务快照和来源片段清单，验证来源版本、缓存可用性、片段标识及时间边界。
2. 对比原始基准与最终有效配置，确定受影响的片段。未修改的片段直接复用兼容的已有缓存。
3. 对修改片段使用原始缓存和用户配置生成替换片段。语速、响度和区间等调整应在适当阶段处理，避免对已处理结果反复叠加增益或变速。
4. 如果文本等调整需要重新生成 TTS，仅更新相应片段所需的阶段；应沿用兼容的上游缓存。
5. 按稳定片段标识替换清单中的对应片段，保留正确的顺序、时间信息与其他元数据。
6. 使用替换后的完整片段清单重新拼接一次，输出编排后的最终音频及关联产物。

缓存缺失或与来源版本不兼容时，必须明确记录错误或降级策略，不能悄悄丢弃用户调整或使用旧片段替代。保留原始基准缓存，避免将编排结果覆盖为下一次还原所依赖的原始数据。

编排 pipeline 遵循后端模块边界：各阶段具有明确的输入、输出与可替换实现；编排器负责选择实现、传递阶段输出及汇总日志。片段变换、缓存访问和产物写入由独立模块负责，不能将这些领域逻辑堆入编排函数。

## 控制台日志与诊断

- 输出任务类型、来源音频、配置快照或版本、阶段名称、开始与结束状态。
- 输出片段总数、缓存复用数、修改数、替换数和重新拼接结果路径。
- 对修改片段记录稳定标识、调整项目及处理结果；缓存问题、降级和失败应明确说明。
- 编排日志进入现有控制台或任务日志通道，用户可以从队列查看执行过程；不能仅写浏览器开发者控制台。
- 保存结构化编排配置及处理审计记录，便于追溯最终结果使用了哪些调整。日志与诊断文件使用 UTF-8，不输出凭据。

## 验收标准

- 调整多个片段的区间、语速和响度后重新打开项目，每个片段的配置都能恢复。
- 单片段设置相互独立，全局设置按保存的作用范围生效；切换片段或模式不丢失已保存配置。
- 当前片段可以试听并还原全部调整，还原不会覆盖其他片段的独立设置。
- 队列明确显示“编排任务”；入队后继续编辑，不改变已入队任务的快照。
- 只修改部分片段时，未修改片段复用缓存，受影响片段使用用户配置生成替换结果，最终整条音频重新拼接。
- 试听与最终输出使用一致的处理规则，已保存的响度和语速调整确实进入最终音频。
- 控制台可查看编排阶段、缓存复用与片段替换统计、结果路径以及失败原因。

## 当前实现与目标的差距

当前页面已接入项目级编排草稿保存、区间与响度保存、中文字幕和日语草稿切换、全局中文字幕优化、基于日语的单段优化、单段 TTS 重新生成、替换音频试听以及编排任务入队。编排 pipeline 使用固定任务快照，复用原始 TTS 或用户重新生成的音频，为只有文本变化的片段生成 TTS，再按页面原声与 TTS 混合时间线重新输出整轨。产物保存在独立的 `arrangement/runs/` 目录，原始基准缓存不被覆盖。

历史生成结果可能没有保留日语原文。单段优化不能把中文伪装成日语或凭空补出原文；没有原文时，用户可补入日语草稿，或使用全局优化直接优化中文。新生成结果会在片段清单中保留已有的 `source_text`。

## 字幕操作与按钮语义

- 草稿标题右侧提供“切换日语 / 切换中文”，两种草稿独立保存。
- 波形切换按钮旁提供“全局字幕优化”，使用识别与实验设置中的字幕优化大模型服务，处理 ASR 翻译、海南鸡直出或已有字幕形成的当前中文字幕。
- 草稿标题旁的魔棒使用无背景、无边框的图标样式，负责将当前日语草稿重新翻译并优化为同一片段的中文。每次点击都重新请求优化服务，不复用上一次优化结果、不拆分片段。
- 中文与日文文本框内部的右上角也提供无背景魔棒，分别提示“优化中文文本”和“优化日文文本”。前者只优化中文，后者只优化日语并保留日语，不触发翻译、不修改另一语言的草稿。
- 全局字幕优化逐片段并发请求：该片段有日语时根据日语生成中文，没有日语时直接优化已有中文。并发量沿用配置中的网络并发数，自动模式使用多个并发请求。每个片段独立完成、独立反馈；失败片段保留原文，成功结果仍保存。
- 全局优化期间片段时间线中的每段右上角显示粉色旋转小圈，该段完成后立即消失，并渐变显示新的中文。时间线显示当前草稿内容，而不始终显示初始字幕。
- 单段和全局优化在后台异步执行，不锁定页面；用户可继续切换片段、试听和编辑。结果逐段保存，仅更新目标语言文本，保留其他调整；请求期间用户修改了相关文本时，不覆盖用户的新编辑。
- 优化失败统一进入全局错误弹窗，不显示页面内的“任务已停止”提示，也不取消其他片段的优化。保留服务错误详情与诊断文件，便于定位失败原因。单段服务使用纯文本响应协议，并兼容编号、代码块和 JSON 文本响应。
- 字幕草稿标题区提供“还原字幕草稿”，恢复该段初始中日文本并保存。该操作仅还原字幕，不清除时间、响度或当前重新生成的试听音频；原有片段还原操作仍用于还原全部独立调整。
- “全局字幕还原”位于全局字幕优化后，恢复所有片段的初始中日文本并保存，保留时间、响度与已生成音频。优化期间暂不可还原，避免后台结果覆盖还原文本。
- 声音总览右侧提供粉色“播放整体”按钮，从整轨开头连续播放原声与当前各段 TTS 的混合结果，应用区间、语速、响度与重新生成的音频。片段切换不打断整轨播放，时间线按播放进度自动选中并滚动到对应片段；再次点击停止。
- 整体播放按钮使用粉色圆角方形样式。未生成或已清理 TTS 缓存的片段保留原声，不中断整轨试听；读取、解码或用户替换音频异常仍进入全局播放错误，错误编号为 `STUDIO_PLAYBACK_FAILED`。
- 整体播放在点击时唤醒音频设备并启动整轨原声，TTS 片段在后台逐段准备并按同一音频时钟加入，不等待全部片段处理完毕。准备期间按钮显示柔和的光晕，且可随时停止；准备较晚的片段按当前进度接入，不从头重播。
- 整体播放在当前 TTS 区域结束且进入下一段的前半预留区时提前选中下一段。底部时间线采用整屏推进：可见范围内切段不滚动，进入下一屏时将新片段对齐到左侧，随后继续从该屏第一个片段推进。
- 在音频工作台和生成结果页后台预加载各段原声、TTS 并共享解码后的 PCM；编排页继续预加载用户替换音频。预加载最多三个并发片段，解码缓存使用 256 MiB 上限与最近使用淘汰，失败读取不永久缓存。自动切段复用已解码数据，无修改时不重复保存草稿。
- “保存草稿”保存文本与编排配置，不立即生成音频。之后的编排任务根据最新中文生成替换片段。
- “重新生成”立即按当前中文调用 TTS，将独立的新音频与生成时文本一并记录，可在页面试听。后续编排直接复用该音频；如果之后再次修改中文，编排任务需要按新文本重新生成，不能误用旧音频。
- 删除检查器中的“输出文件”区域。底部“重新编排”保存全部调整，提交带“编排任务”标记的队列任务并打开队列。

字幕优化需清除识别窗口重叠造成的机械重复、不可朗读的装饰与控制字符、时间戳和格式标记，修复错别字、断裂句及生硬直译，使用自然停顿标点，并在含义明确时转换数字、日期、单位和缩写的读法。保留有意强调、真实语气、人物关系、专名和核心含义；不猜测、不扩写、不改变片段边界。情绪标签遵循所选 TTS 引擎支持范围。
